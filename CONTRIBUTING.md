# Contributing

This is a personal portfolio, so new features are not accepted from outside.
Bug reports and small fixes are welcome.

- **Found a bug** (broken layout, typo, a link that does not work)? [Open an issue](https://github.com/alamin2507/portfolio/issues/new/choose).
- **Found a security problem?** Do not open an issue; follow [SECURITY.md](SECURITY.md).
- **Small fix?** Open a pull request. Keep it focused on one change, make sure `npm run build` passes, and fill in the checklist.

How the project is planned and built is described in [`docs/PRD.md`](docs/PRD.md) and [`docs/SOP.md`](docs/SOP.md).
