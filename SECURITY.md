# Security policy

This is a static website with no backend, database or user accounts.
Security headers (CSP, HSTS and others) are set in [`vercel.json`](vercel.json).

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- Use **[Report a vulnerability](https://github.com/alamin2507/portfolio/security/advisories/new)** on this repository.

Include what you found, where, and how to reproduce it. You can expect a reply within 7 days.

## Supported version

Only the live site at https://sayem.me (the `main` branch) is maintained.
